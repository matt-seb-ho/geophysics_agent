# Example Usage

This document walks through a complete example of setting up and running the LLM evaluation pipeline.

## Scenario

You have an experiment called `ExampleEDPWellbore` with:
- An instruction file describing what to generate
- Ground truth XML files from the GEOS repository
- Agent-generated XML files you want to evaluate

## Step-by-Step Guide

### 1. Directory Structure (Before Setup)

```
data/eval/experiments_subset/
└── ExampleEDPWellbore/
    ├── instructions.txt
    └── inputs/
        └── edpWellbore_base.xml      # Generated by agent
```

### 2. Set Up Ground Truth Directory

```bash
# Auto-detect the XML file from inputs/
uv run python scripts/eval/setup_ground_truth.py \
    --experiment data/eval/experiments_subset/ExampleEDPWellbore \
    --auto-detect
```

**Output:**
```
Setting up ground truth for: ExampleEDPWellbore
  Auto-detected files: edpWellbore_base.xml
  ✓ Created: ground_truth/manifest.json
  ✓ Created: ground_truth/README.md
  → Next: Copy ground truth XML files to data/eval/experiments_subset/ExampleEDPWellbore/ground_truth
```

### 3. Directory Structure (After Setup)

```
data/eval/experiments_subset/
└── ExampleEDPWellbore/
    ├── instructions.txt
    ├── ground_truth/
    │   ├── manifest.json
    │   ├── README.md
    │   └── (empty - waiting for ground truth files)
    └── inputs/
        └── edpWellbore_base.xml
```

### 4. Copy Ground Truth Files

Copy your reference XML files into the `ground_truth/` directory:

```bash
# Example: Copy from GEOS repository
cp data/geos_source/examples/edpWellbore/edpWellbore_base.xml \
   data/eval/experiments_subset/ExampleEDPWellbore/ground_truth/
```

**Result:**
```
data/eval/experiments_subset/
└── ExampleEDPWellbore/
    ├── instructions.txt
    ├── ground_truth/
    │   ├── manifest.json
    │   ├── README.md
    │   └── edpWellbore_base.xml    # ✓ Ground truth added
    └── inputs/
        └── edpWellbore_base.xml    # Generated by agent
```

## Advanced: Multi-File with Imports

For experiments with multiple XML files and imports:

### 1. Set up with additional files

```bash
uv run python scripts/eval/setup_ground_truth.py \
    --experiment data/eval/experiments_subset/TutorialHydraulic \
    --entry-point case.xml \
    --additional base.xml
```

### 2. Copy ground truth files

```bash
cp data/geos_source/examples/hydraulicFracture/case.xml \
   data/eval/experiments_subset/TutorialHydraulic/ground_truth/

cp data/geos_source/examples/hydraulicFracture/base.xml \
   data/eval/experiments_subset/TutorialHydraulic/ground_truth/
```

### 3. Evaluate with import resolution

```bash
uv run python scripts/eval/llm_judge_xml.py \
    --ground-truth data/eval/experiments_subset/TutorialHydraulic/ground_truth/case.xml \
    --generated data/eval/experiments_subset/TutorialHydraulic/inputs/case.xml \
    --resolve-imports
```

This will resolve any `<Included File="base.xml"/>` tags before comparison.

### Understanding RAG Accuracy

The `--source-path` parameter should point to the RST documentation file that the experiment is based on. For example:

- If evaluating `ExampleEDPWellbore`, use: `"src/docs/sphinx/advancedExamples/edpWellbore/Example.rst"`
- If evaluating `TutorialDeadOilEgg`, use: `"src/docs/sphinx/basicExamples/deadOilEgg/Example.rst"`

This metric measures whether the agent is retrieving relevant documentation chunks during its execution. High relevance (>60%) indicates the RAG system is working well.

## Tips

1. **Use auto-detect for quick setup:**
   ```bash
   uv run python scripts/eval/setup_ground_truth.py -d data/eval/experiments_subset --auto-detect
   ```

2. **Test single file first** before batch evaluation to verify ground truth is correct

3. **Use different models** for different evaluation needs:
   - Fast: `google/gemini-flash-1.5-8b`
   - Balanced: `anthropic/claude-3.5-sonnet` (default)
   - Thorough: `anthropic/claude-opus-4`

4. **Save results** to track progress over time:
   ```bash
   uv run python scripts/eval/batch_evaluate.py \
       -d data/eval/experiments_subset \
       -o data/eval/results_$(date +%Y%m%d).json
   ```

5. **Filter specific experiments** for targeted evaluation:
   ```bash
   uv run python scripts/eval/batch_evaluate.py \
       -d data/eval/experiments_subset \
       -e ExampleEDPWellbore TutorialDeadOilEgg
   ```
