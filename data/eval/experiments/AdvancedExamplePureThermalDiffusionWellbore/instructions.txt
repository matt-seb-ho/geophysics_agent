# Natural Language Specification for Pure Thermal Diffusion Around a Wellbore Simulation

## 1. Simulation Type and Physical Problem

This simulation models pure thermal diffusion around a wellbore using GEOS's thermal single-phase flow solver. The problem represents a validation study comparing numerical results against the analytical solution from Wang and Papamichos (1994).

The physical scenario involves:
- A wellbore with a uniform temperature applied on its inner curved surface
- Temperature diffusing radially outward into the surrounding rock medium
- Pure thermal diffusion only (no thermal convection or fluid flow)
- To achieve pure thermal diffusion behavior, fluid pressure must be set to zero everywhere and fluid heat capacity must be set to a negligible value

The analytical solution being validated is: T(r) = T_in × sqrt(R_in/r) × erfc((r - R_in)/(2×sqrt(c_T×t))), where r is the radial coordinate, T_in is the wellbore surface temperature, R_in is the wellbore inner radius, c_T is the thermal diffusion coefficient (thermal conductivity divided by volumetric heat capacity), and t is time.

## 2. Required Solver Parameters and Settings

Configure a thermal single-phase flow solver with the following characteristics:
- Solver type: SinglePhaseFVM (or equivalent thermal single-phase flow solver)
- The solver must be capable of handling thermal transport
- Enable the thermal option for single-phase flow
- The problem is inherently transient (time-dependent diffusion)
- Time stepping should be configured to capture the diffusion evolution

## 3. Mesh Requirements

The mesh should represent a 2D wellbore geometry:
- Two-dimensional domain (radial cross-section around wellbore)
- The geometry must include a wellbore inner surface at radius R_in
- Extend radially outward to a far-field boundary
- Use appropriate element types for 2D analysis (likely quadrilateral or triangular elements)
- The mesh should be refined near the wellbore surface where temperature gradients are steepest
- The mesh must have named sets/regions for:
  - The wellbore inner curved surface (for applying temperature boundary condition)
  - The far-field boundary (for applying far-field temperature)
  - The entire domain (for initial conditions)

## 4. Material Properties and Constitutive Models

### Solid Internal Energy Model
Create a SolidInternalEnergy constitutive model to define the volumetric heat capacity of the rock medium around the wellbore. This should be a linear model specifying:
- Volumetric heat capacity of the solid matrix
- Reference temperature for the energy calculation

### Thermal Conductivity Model
Create a SinglePhaseConstantThermalConductivity constitutive model to define the thermal conductivity of the medium. This requires:
- A constant thermal conductivity value for the rock
- The thermal diffusion coefficient c_T is derived from: c_T = thermal conductivity / volumetric heat capacity

### Fluid Model
Create a ThermalCompressibleSinglePhaseFluid constitutive model with:
- Volumetric heat capacity set to a negligible (near-zero) value to exclude thermal convection effects
- Standard fluid properties (density, viscosity, compressibility) though these will have minimal effect since pressure is zero
- Thermal expansion coefficient (can be set to nominal value)

## 5. Initial and Boundary Conditions

### Temperature Field Specifications
All temperature conditions are applied as Dirichlet face boundary conditions using the faceManager:

**Initial Temperature:**
- Apply an initial temperature field to the entire domain
- This sets the starting temperature distribution before the wellbore heating begins

**Wellbore Surface Temperature (T_in):**
- Apply a fixed/imposed temperature on the curved inner wellbore surface
- This represents the heat source driving the diffusion
- Use appropriate face set name corresponding to the wellbore inner surface

**Far-Field Temperature:**
- Apply a fixed temperature at the far-field boundary
- This maintains the original formation temperature at distance from the wellbore

### Pressure Field Specifications
Although this is a pure thermal diffusion problem, GEOS requires pressure specifications since thermal transfer is coupled with fluid flow:

**Fluid Pressure:**
- Set fluid pressure to zero everywhere in the domain
- Apply as both initial condition and boundary conditions
- This effectively eliminates fluid flow and convective heat transfer
- Use faceManager to apply pressure boundary conditions

## 6. Numerical Method Specifications

- Finite volume method (FVM) discretization for thermal transport
- The solver handles the diffusion equation implicitly
- Time integration should use appropriate time steps to resolve the thermal diffusion timescale
- The characteristic diffusion time scale relates to: t ~ L²/c_T, where L is a characteristic length
- Nonlinear solver tolerances should be set appropriately for convergence
- Linear solver settings for the coupled thermal-flow system

## 7. Output Requirements

Configure outputs to:
- Record temperature field at multiple time steps for comparison with analytical solution
- Output temperature profiles along the radial direction from wellbore surface outward
- Enable visualization of the 2D temperature distribution
- Store results at time intervals that capture the diffusion front evolution
- Include nodal or cell-centered temperature values
- Output format should support plotting temperature vs. radial distance for validation against the analytical Wang and Papamichos (1994) solution

The validation comparison should show good agreement between GEOS numerical results and the analytical solution for radial temperature distribution at various times.
