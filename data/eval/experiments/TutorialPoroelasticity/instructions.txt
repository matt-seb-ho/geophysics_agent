# Natural Language Specification for Poromechanics XML Configuration

## Simulation Overview

This configuration defines a coupled poroelastic simulation solving a Terzaghi-type consolidation problem. The simulation models the consolidation of a fluid-saturated poroelastic column under instantaneous compressive loading. The problem couples single-phase fluid flow with small-strain Lagrangian solid mechanics to compute displacement and pressure fields as functions of time.

## Solver Configuration

### Coupled Solver Structure

The simulation requires three solver definitions:

1. **Flow Solver**: Create a single-phase flow solver of type `SinglePhaseFVM`. Name this solver "SinglePhaseFlowSolver" (or similar user-defined name). This handles the fluid flow physics using finite volume discretization.

2. **Solid Mechanics Solver**: Create a solid mechanics solver of type `SolidMechanicsLagrangianFEM`. Name this solver "LinearElasticitySolver" (or similar user-defined name). This handles the mechanical deformation using finite element discretization.

3. **Coupling Solver**: Create a poromechanics coupling solver of type `SinglePhasePoromechanics`. Name this solver "PoroelasticitySolver" (or similar user-defined name). This solver must:
   - Reference the flow solver by its name ("SinglePhaseFlowSolver")
   - Reference the solid mechanics solver by its name ("LinearElasticitySolver")
   - Specify the discretization method as "FE1"
   - Target the region named "Domain"

## Numerical Methods Specification

### Finite Element Method

Define a finite element discretization method named "FE1" with the following characteristics:
- Use linear basis functions
- Apply Gaussian quadrature rules for numerical integration
- This method will be used by both the coupling solver and solid mechanics solver

### Finite Volume Method

Define a finite volume discretization for the flow solver:
- Use a two-point flux approximation (TPFA) scheme for computing fluxes between cells

## Mesh Requirements

Use the internal mesh generator to create a beam-like columnar mesh with the following specifications:

- **Element Distribution**:
  - 21 elements along the X-axis (column length direction)
  - 1 element along the Y-axis
  - 1 element along the Z-axis

- **Element Type**: Hexahedral elements (C3D8)

- **Element Dimensions**: Each element should be 1 meter × 1 meter × 1 meter (uniform cubic elements)

- **Total Column Dimensions**: The column has a length of 10.0 meters with unit cross-section (1m × 1m)

- **Region Definition**: Define a single region named "Domain" encompassing all elements

## Material Properties and Constitutive Models

### Solid Material (Poroelastic)

Define a poroelastic solid material in the Constitutive section with the following properties:

- **Young's Modulus (E)**: 10,000 Pa (10^4 Pa)
- **Poisson's Ratio (ν)**: 0.2
- **Biot's Coefficient (b)**: 1.0
- **Porosity (φ)**: 0.3
- **Permeability (κ)**: 1.0 × 10^-4 m² (isotropic)

### Fluid Properties

Define fluid properties with the following values:

- **Fluid Density (ρf)**: 1.0 kg/m³
- **Fluid Compressibility (cf)**: 0.0 Pa^-1 (incompressible fluid)
- **Fluid Viscosity (μ)**: 1.0 Pa·s

## Boundary Conditions

Define boundary conditions in the FieldSpecifications section:

### Mechanical Boundary Conditions

1. **Applied Load**: On the top face of the column (the permeable face):
   - Apply a constant compressive traction of magnitude 1.0 Pa
   - This load is applied instantaneously at time t = 0

2. **Roller Constraints**: On all other boundaries (bottom and sides):
   - Apply roller constraints preventing normal displacement
   - These surfaces should have zero normal displacement while allowing tangential movement

### Hydraulic Boundary Conditions

1. **Permeable Boundary**: The loaded (top) face is the only face permeable to fluid flow
   - This serves as a drainage boundary

2. **Impervious Boundaries**: All remaining boundaries (bottom and sides):
   - Apply no-flow (impervious) conditions
   - Zero fluid flux across these surfaces

## Initial Conditions

- The column is initially fully saturated with fluid
- At t = 0, the load is applied instantaneously, generating an initial uniform pressure of p0 = 1.0 Pa throughout the column

## Time Stepping and Events

Configure the simulation timing in the Events section:

- **Total Simulation Time**: 90 seconds (this corresponds to the characteristic consolidation time tc = L²/cc where cc = 1.111 m²/s)
- The timestep sizes should be chosen appropriately relative to the characteristic consolidation time
- Include periodic events for solver execution and output writing

## Output Requirements

Configure outputs to capture:

1. **Field Data**:
   - Displacement field (vector field for all nodes/elements)
   - Pressure field (scalar field throughout the column)

2. **Temporal Resolution**: Output at multiple time points to capture the transient consolidation behavior for comparison with the analytical solution

3. **Spatial Resolution**: Results along the column length (X-axis) to verify against the analytical pressure distribution

## File Structure Notes

The configuration may be split across multiple XML files:
- A base configuration file containing solver definitions, numerical methods, and constitutive models
- A case-specific file containing mesh, boundary conditions, and time stepping parameters

The case-specific file can include the base file and override or supplement its contents.

## Expected Solver Behavior

The fully implicit coupled solver should converge in a single Newton iteration per timestep since this is a linear problem. Monitor the residual values for both solid (RSolid) and fluid (RFluid) mechanics to verify convergence.
