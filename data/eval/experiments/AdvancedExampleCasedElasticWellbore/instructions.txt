# Natural Language Specification for Cased Elastic Wellbore Simulation

## Overview and Simulation Type

This specification describes a solid mechanics simulation for a cased wellbore subjected to a pressure test. The model represents a completed wellbore consisting of three concentric cylindrical regions: an inner steel casing, a cement sheath surrounding the casing, and the outer rock formation. The simulation assumes isotropic linear elastic behavior for all three materials and enforces perfect bonding (no separation) at the casing-cement and cement-rock contact interfaces.

## Solver Configuration

### Primary Solver
Configure a Lagrangian finite element solid mechanics solver using the solver type "SolidMechanicsLagrangianFEM". This problem does not involve fluid flow, so only the mechanical solver is needed.

### Target Regions and Materials
The solver must be configured to target three distinct regions corresponding to:
1. The steel casing region
2. The cement sheath region
3. The rock formation region

Each region must be associated with its corresponding solid material through the solver's material assignment parameters.

## Mesh Specification

### Mesh Generator Type
Use the internal wellbore mesh generator ("InternalWellbore") to create the computational domain.

### Geometric Parameters
- **Radii**: Define a vector of radii that specifies the boundaries of each cylindrical region - the inner radius of the casing, the outer radius of the casing (inner radius of cement), the outer radius of the cement sheath (inner radius of rock), and the far-field boundary of the rock formation.
- **Angular extent**: Specify the theta angle from 0 to 360 degrees for a full circumferential geometry. Note that reduced domains can be modeled using 0 to 180 degrees for half geometry or 0 to 90 degrees for quarter geometry.
- **Well trajectory**: Define a vertical well trajectory.

### Mesh Control Options
- **Automatic radial element spacing**: Enable the auto-spacing option for radial elements, which optimally increases element size from the near-wellbore zone to the far-field zone. Apply this automatic spacing specifically to the rock formation region.
- **Cartesian outer boundary**: Enable the option to transform the far-field boundary into a squared (Cartesian-aligned) shape. This facilitates the application of boundary conditions on the outer surfaces.

### Element Definitions
- Define cell block names corresponding to each of the three regions (casing, cement sheath, and rock)
- Specify appropriate element types for each cell block region

## Material Properties and Constitutive Models

### Constitutive Model Type
Use the isotropic linear elastic constitutive model ("ElasticIsotropic") for all three materials.

### Material Definitions
Define three separate materials:

1. **Steel** (for casing): Specify elastic properties using appropriate Lamé parameters or equivalent elastic moduli (Young's modulus and Poisson's ratio). Steel typically has high stiffness values.

2. **Cement** (for cement sheath): Specify elastic properties appropriate for wellbore cement material.

3. **Rock** (for formation): Specify elastic properties appropriate for the surrounding rock formation.

Note: While density values must be provided for each material definition, they are not utilized in this quasi-static elastic analysis.

## Boundary Conditions

### Far-Field Boundary Constraints
Apply roller boundary conditions on the far-field boundaries. These constraints prevent normal displacement while allowing tangential movement along the outer surfaces of the domain.

### Internal Pressure Loading
Configure a traction boundary condition on the inner surface of the casing:
- **Target surface**: Apply to the nodeset named "rneg" which is automatically generated by the internal wellbore mesh generator for the inner casing face
- **Traction type**: Set to "normal" to simulate a casing pressure test where pressure acts perpendicular to the inner casing surface
- **Magnitude and sign**: Specify the pressure magnitude with a negative scale value. The negative sign is required because GEOS uses a negative sign convention for compressive stresses, and the applied pressure represents a compressive load on the casing interior.

## Initial Conditions

No specific initial stress or displacement conditions are described for this problem. The simulation begins from an unstressed reference state.

## Numerical Method Specifications

The simulation employs the Lagrangian finite element method for spatial discretization of the solid mechanics equations. The problem is linear elastic, so it should converge in a single iteration without requiring nonlinear solver settings.

## Output Requirements

The simulation should output results that allow for extraction and visualization of:
- Radial stress component (σ_rr) throughout all three regions
- Hoop stress component (σ_θθ) throughout all three regions
- Displacement fields for validation

Results should be extractable along radial profiles to compare against the analytical solution based on the Hervé and Zaoui (1995) formulation for multi-layer cylinders.

## File Organization

The configuration should be organized into base and benchmark XML files:
- A base file containing common definitions (constitutive laws, boundary conditions)
- A benchmark file containing solver and mesh specifications specific to the validation study

The files should be structured to allow inclusion/referencing between them for modularity.
