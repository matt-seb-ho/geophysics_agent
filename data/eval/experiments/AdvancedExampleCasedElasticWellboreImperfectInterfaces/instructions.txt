# Natural Language Specification for Cased Elastic Wellbore with Imperfect Interfaces Simulation

## 1. Simulation Type and Physical Problem

This simulation models a cased wellbore with imperfect contact interfaces using the LagrangianContact solver. The wellbore consists of three concentric cylindrical layers:
- Inner layer: Steel casing
- Middle layer: Cement sheath
- Outer layer: Rock formation

All three materials are assumed to exhibit isotropic linear elastic behavior. The simulation captures the debonding behavior at the casing-cement interface when radial tension is applied to the inner face of the wellbore. The contact surfaces between materials are modeled using a Lagrangian contact approach.

The physical behavior being validated is that under radial tension on the inner casing surface, the casing debonds from the cement layer, resulting in stress-free conditions at the outer casing face and inner cement face. This leads to zero displacement jump at the cement-rock interface, while the displacement jump at the casing-cement interface equals the radial displacement at the outer radius of the casing.

## 2. Solver Parameters and Settings

### Primary Solver
- Solver type: LagrangianContact
- This solver requires a stabilization method specification via the stabilizationName parameter

### Secondary Solver
- Solver type: SurfaceGenerator
- Purpose: Generates imperfect contact surfaces at the interfaces
- The rockToughness parameter exists by default but should be omitted for this simulation

### Coupling Requirements
- The simulation requires definition of both the contact mechanics solver and the surface generation solver
- Tasks must be defined for collecting displacement jump data across contact surfaces

## 3. Mesh Requirements

### Geometry Type
- Cylindrical geometry representing a wellbore cross-section
- The mesh must define three distinct annular regions for casing, cement, and rock

### Cylinder Geometry Specifications for Interface Selection
Two Cylinder geometry objects must be defined to select the curved nodesets at the interfaces:

**Casing-Cement Interface Cylinder:**
- Specify firstFaceCenter: coordinates of one end plane center
- Specify secondFaceCenter: coordinates of the opposite end plane center
- Specify innerRadius: inner radius of the selection annulus
- Specify outerRadius: outer radius of the selection annulus

**Cement-Rock Interface Cylinder:**
- Same parameter structure as above but with different radii corresponding to the cement-rock boundary

The innerRadius parameter is essential for both cylinders as it creates hollow cylinder (annulus) selections that capture only the interface nodes rather than entire circular regions.

## 4. Material Properties and Constitutive Models

### Solid Materials
Three isotropic linear elastic materials must be defined:

**Steel Casing:**
- Constitutive model: Isotropic linear elastic
- Required properties: Young's modulus, Poisson's ratio, and density

**Cement Sheath:**
- Constitutive model: Isotropic linear elastic
- Required properties: Young's modulus, Poisson's ratio, and density

**Rock Formation:**
- Constitutive model: Isotropic linear elastic
- Required properties: Young's modulus, Poisson's ratio, and density

### Contact Material
- A contact constitutive model must be defined for the imperfect interfaces
- For this purely mechanical problem without fluid flow or shearing stress, the detailed contact parameters can be omitted or set to default values
- The contact material is referenced in the Fracture surface element region

## 5. Initial and Boundary Conditions

### Boundary Conditions
- Radial tension applied to the inner face of the wellbore (inner surface of the casing)
- The applied tension stress varies with time as specified in the loading function
- Far-field or outer boundary conditions on the rock formation outer surface (not explicitly detailed but required for closure)

### Loading
- Time-varying tension stress on the inner casing surface
- The loading causes debonding at the casing-cement interface

## 6. Region and Element Definitions

### Cell Element Regions
- Three distinct regions for casing, cement, and rock, each associated with their respective material

### Surface Element Region
- Define a Fracture region for the imperfect contact surfaces
- This region encompasses both the casing-cement and cement-rock interfaces
- The faceBlock must be named (e.g., "faceElementSubRegion") for use in displacement jump collection Tasks
- A materialList must reference the contact material
- The defaultAperture parameter (hydraulic aperture) should be omitted for this purely mechanical problem

## 7. Numerical Method Specifications

### Stabilization
- A stabilization method must be defined in the NumericalMethods block
- This stabilization is referenced by name in the LagrangianContact solver via the stabilizationName parameter
- The stabilization is required for the proper functioning of the contact algorithm

## 8. Events Configuration

### Surface Generation Event
- Define a solo event (single execution) for generating the imperfect contact surfaces
- This event must target the SurfaceGenerator solver
- Should execute at the beginning of the simulation before mechanical loading

### Displacement Jump Collection Events
- Define two periodic events for collecting displacement jump data across the interfaces
- These events should target the appropriate history collection Tasks
- The periodicity should capture the time-varying response due to the time-dependent loading

## 9. Tasks and Output Requirements

### History Collection Tasks
- Define Tasks to collect displacement jump data across contact surfaces
- The Tasks must reference the faceElementSubRegion defined in the Fracture region
- Separate Tasks may be needed for casing-cement and cement-rock interfaces

### Output Specifications
- Configure outputs to capture displacement jump time history
- Results should show:
  - Zero displacement jump at the cement-rock interface under tension loading
  - Homogeneous, time-varying displacement jump at the casing-cement interface
- Output format should support comparison with analytical solutions where radial displacement follows u_r = Ar - B/r

### Expected Results for Validation
- The displacement jump at the casing-cement interface should match analytical predictions
- The cement-rock interface should show zero displacement jump, confirming no strain in cement and rock layers after debonding

## 10. File Organization

The configuration should be organized into:
- A base XML file containing: solvers, numerical methods, surface element regions, and contact materials
- A benchmark XML file containing: geometry definitions (Cylinder objects for interface selection), events, and case-specific parameters
