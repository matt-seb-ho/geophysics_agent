# Natural Language Specification for Deviated Elastic Wellbore Simulation

## Overview and Simulation Type

This simulation models a deviated (inclined) wellbore problem with open hole completion using solid mechanics. The problem considers a segment of wellbore surrounded by isotropic linear elastic rock formation. The simulation assumes undrained conditions, meaning no fluid flow occurs in the rock formation. Both far-field stresses and gravity effects are explicitly excluded from this analysis. The wellbore is subjected only to mud pressure applied at the wellbore wall. This is a validation study comparing numerical results against analytical solutions for radial and hoop stresses around the wellbore.

## Solver Configuration

Configure a single solid mechanics solver using the Lagrangian finite element method (SolidMechanicsLagrangianFEM). This solver handles the elastic deformation of the rock formation around the wellbore. No coupled fluid flow solver is needed since undrained conditions are assumed. The solver should target the mesh region containing the rock formation around the wellbore.

## Mesh Requirements

Use the internal wellbore mesh generator (InternalWellbore) to create the computational domain. The mesh configuration should include:

**Radial Direction:**
- Define a radius vector that specifies the wellbore radius as the inner boundary and extends outward to define the surrounding rock formation extent
- Enable automatic spacing of radial elements by setting the autoSpaceRadialElems parameter to 1, which optimally increases element size from the near-wellbore zone to the far-field zone

**Tangential Direction:**
- Specify theta angle ranging from 0 to 180 degrees to model half of the domain, taking advantage of geometric symmetry
- Note: For more complex scenarios, the full 360-degree domain could be modeled

**Wellbore Trajectory:**
- Define the trajectory to create a wellbore inclined at 45 degrees within the x-z plane
- The trajectory parameter controls the orientation and deviation of the wellbore

**Outer Boundary Shape:**
- Set useCartesianOuterBoundary to 0 to maintain a cylindrical/circular outer boundary rather than transforming it to a squared Cartesian-aligned shape
- This setting is appropriate for a single radial region configuration

The mesh generator will automatically create nodesets including "rneg" for the wellbore wall surface, which will be used for applying boundary conditions.

## Material Properties and Constitutive Model

Define an isotropic linear elastic constitutive model for the rock formation surrounding the wellbore. The required material properties include:

- **Constitutive Model Type:** Elastic Isotropic
- **Default Density:** Include a density value, though it will not affect results since gravity is neglected in this simulation
- **Elastic Properties:** Specify Young's modulus and Poisson's ratio appropriate for the rock formation being modeled

The material should be assigned to the rock region generated by the wellbore mesh generator.

## Boundary Conditions

**Far-Field Boundaries:**
Apply roller constraints (zero normal displacement) on all far-field boundary surfaces. This prevents rigid body motion while allowing the boundaries to slide tangentially. No in-situ stresses are applied to these boundaries.

**Wellbore Wall (Mud Pressure):**
- Apply a traction boundary condition to represent the mud pressure acting on the wellbore wall
- Target the nodeset named "rneg" which is automatically generated by the internal wellbore mesh generator to identify the wellbore wall face
- Set the traction type to "normal" to apply pressure perpendicular to the wellbore wall surface
- Use a negative scale value for the pressure magnitude, following GEOS sign convention where compressive stresses are negative
- The mud pressure value (p₀) should be specified according to the desired loading condition

## Initial Conditions

No specific initial stress state is required since far-field stresses are excluded from this problem. The simulation starts from an unloaded state and applies only the mud pressure at the wellbore wall.

## Numerical Method Specifications

The simulation uses the Lagrangian finite element method for solid mechanics. The mesh should be refined adequately near the wellbore wall where stress gradients are highest, which is facilitated by the automatic radial element spacing feature. The half-symmetry model (0 to 180 degrees) reduces computational cost while capturing the full physics due to the symmetric nature of the problem.

## Output Requirements

Configure outputs to capture:
- Displacement fields in the rock formation
- Stress tensor components, particularly:
  - Radial stress (σ_rr) for comparison with analytical solution: σ_rr = p₀(a²/r²)
  - Hoop/tangential stress (σ_θθ) for comparison with analytical solution: σ_θθ = -p₀(a²/r²)

where p₀ is the applied mud pressure, a is the wellbore radius, and r is the radial coordinate from the wellbore center.

Results should be output at locations along radial lines extending from the wellbore wall to enable validation against the analytical expressions.

## File Structure

The configuration should be organized into base and benchmark XML files:
- A base file containing common elements such as constitutive models and boundary conditions
- A benchmark file containing mesh specifications and solver configurations
- The benchmark file should include/reference the base file
