# Natural Language Specification for Single Fracture Under Shear Compression Simulation

## Overview and Physical Problem

Create an XML configuration file for simulating a single inclined fracture under uniaxial compressive stress using Lagrangian contact mechanics. The simulation models an inclined fracture placed in an infinite, homogeneous, isotropic, and elastic medium subjected to horizontal compression. The physical phenomena include mechanical deformation of the surrounding rock and frictional sliding along the fracture plane. The simulation assumes plane strain deformation conditions and uses the Coulomb failure criterion for frictional contact.

This is a validation benchmark case comparing numerical results against analytical solutions for normal traction and slip distributions on the fracture surface.

## Input File Structure

The configuration requires multiple XML files that work together:
- A base configuration file containing common definitions
- A benchmark-specific file containing mesh and solver coupling definitions
- A contact mechanics configuration file with solver specifications

An external mesh file in VTU format named "crackInPlane_benchmark.vtu" must also be provided.

## Solver Configuration

### Primary Coupling Solver
Define a Lagrangian contact solver with the name "lagrangiancontact". This solver couples rock deformation with fracture mechanics. Configure it to operate on two target regions: the continuum region named "Region" and the discontinuum fracture region named "Fracture". Reference the contact constitutive law named "fractureMaterial" for the fracture elements.

### Solid Mechanics Solver
Configure a solid mechanics solver using the SolidMechanicsLagrangianFEM formulation. Set the problem type to "QuasiStatic" to neglect inertial effects. The solver should use the discretization scheme named "FE1" defined in the numerical methods section. Reference the solid material named "rock" for the computational domain.

### Surface Generator
Include a SurfaceGenerator solver to define the fracture region and specify rock toughness properties.

## Mesh Specification

Import an external unstructured mesh using the VTKMesh importer. The mesh file path should reference "crackInPlane_benchmark.vtu" using either a relative or absolute path from the main XML file location. Assign the label "CubeHex" to this mesh object.

The mesh contains:
- Quadrilateral elements for the 2D domain
- Interface elements for the fracture representation
- Mesh refinement conforming to the fracture geometry

A Geometry section must be included to specify the fracture geometry that the mesh conforms to.

## Numerical Methods

Define a finite element discretization scheme named "FE1" for use by the solid mechanics solver. This should support the Lagrangian finite element formulation appropriate for the quadrilateral elements in the imported mesh.

## Constitutive Models

### Rock Material
Define an elastic isotropic material named "rock" using the ElasticIsotropic model. Specify the following mechanical properties in SI units:
- Bulk Modulus: 16.67 GPa (1.667e10 Pa)
- Shear Modulus: 10.0 GPa (1.0e10 Pa)
- Include appropriate density value

### Fracture Contact Material
Define a Coulomb friction model named "fractureMaterial" for the frictional contact behavior on the fracture surface. Specify:
- Cohesion: 0.0 (zero cohesion, purely frictional)
- Friction Coefficient: 0.577350269 (corresponding to a 30-degree friction angle; this is tan(30°))

## Geometric Parameters

The fracture geometry should reflect:
- Fracture half-length: 1.0 meter (total fracture length of 2.0 meters)
- Inclination angle: 20.0 degrees from horizontal

## Initial Conditions

Initialize the stress field with a remote uniaxial horizontal compressive stress. In the FieldSpecifications section, set the initial horizontal stress (σx) to -1.0e8 Pa (-100.0 MPa). Note that GEOS uses a negative sign convention for compressive stresses.

## Boundary Conditions

Apply the following boundary conditions in the FieldSpecifications section:
- Apply roller constraints on the outer boundaries of the computational domain to represent the infinite medium approximation
- The roller constraints should allow displacement parallel to the boundary while preventing displacement normal to the boundary

## Time History and Output Configuration

### Tasks Section
Define two PackCollection tasks for collecting time history data from the fracture surface:

1. A task named "tractionCollection" that collects the field named "traction" from the fracture surface
2. A task named "displacementJumpCollection" that collects the field named "displacementJump" from the fracture surface

### Events Section
Create PeriodicEvent entries to trigger the time history collection tasks at appropriate intervals during the simulation.

### Output Files
Configure the following outputs:
- HDF5 time history files that will be generated as "displacementJump_history.hdf5" and "traction_history.hdf5" containing the collected field data, simulation time, and element center coordinates in the local coordinate system
- VTK format output files for visualization in Paraview, capturing displacement fields (particularly the y-component of displacement, uy) and fracture slip values

## Summary of Key Numerical Values

| Parameter | Value | Units |
|-----------|-------|-------|
| Bulk Modulus | 16.67 | GPa |
| Shear Modulus | 10.0 | GPa |
| Compressive Stress | -100.0 (or -1.0e8 Pa) | MPa |
| Friction Angle | 30.0 | degrees |
| Friction Coefficient | 0.577350269 | dimensionless |
| Cohesion | 0.0 | Pa |
| Inclination Angle | 20.0 | degrees |
| Fracture Half Length | 1.0 | meters |

## File Organization

The XML configuration should be structured to support file inclusion/referencing, with:
- Base definitions in "SingleFracCompression_base.xml"
- Benchmark-specific mesh configuration in "SingleFracCompression_benchmark.xml"
- Contact mechanics solver definitions in "ContactMechanics_SingleFracCompression_benchmark.xml"
- External mesh file "crackInPlane_benchmark.vtu" in the same directory
