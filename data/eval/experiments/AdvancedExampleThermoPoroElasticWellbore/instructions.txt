# Natural Language Specification for ThermoPoroElastic Wellbore Simulation

## 1. Simulation Type and Physical Problem

This simulation models a thermoporoelastic open wellbore problem using GEOS. The physical scenario involves a wellbore drilled through a rock formation that is subjected to a uniform temperature change applied on its inner surface. The rock formation exhibits isotropic linear thermoporoelastic behavior. The problem assumes plane strain conditions (no deformation along the wellbore axis) and axisymmetric conditions (quarter symmetry).

The solver to use is the **SinglePhasePoromechanics** solver with the **thermal option enabled**. This solver couples solid mechanics, single-phase fluid flow, and heat transfer. Gravitational effects should be ignored in this simulation. The coupling should be fully coupled (not one-way coupling).

## 2. Mesh Requirements

Use the **InternalWellbore** internal mesh generator to create the computational domain.

### Geometric Parameters:
- Define a **radius vector** specifying the inner wellbore radius and the far-field boundary radius of the surrounding rock formation
- Set the **theta** angle range from **0 to 90 degrees** to model a quarter of the wellbore geometry (exploiting axisymmetric symmetry)
- Define a **vertical well trajectory** (the trajectory coordinates should specify a vertical orientation)
- Model only a **single horizontal layer** since plane strain conditions apply and thermal diffusion occurs only along the radial direction

### Mesh Optimization:
- Enable the **autoSpaceRadialElems** parameter to automatically optimize element sizing, with smaller elements near the wellbore and progressively larger elements toward the far-field boundary
- This creates a radially-graded mesh that captures the steep gradients near the wellbore while maintaining computational efficiency

## 3. Material Properties and Constitutive Models

### Thermoelastic Solid Properties:
Define the following properties within a thermoelastic constitutive model:
- **Drained bulk elastic modulus** (K)
- **Drained shear elastic modulus** (G)
- **Drained linear thermal expansion coefficient** (α) - relates stress change to temperature variation
- **Solid density** - must be defined even though gravitational effects are ignored

### Poroelastic Properties:
Define porosity and skeleton properties:
- **Porosity** of the rock formation
- **Elastic bulk modulus of the solid skeleton** (Ks) - the intrinsic grain bulk modulus

### Thermal Properties:
Specify two separate property sets:
- **Thermal conductivity** of the rock formation
- **Volumetric heat capacity** of the rock formation

### Permeability Properties:
- Define the **permeability** of the rock formation (isotropic)

### Fluid Properties:
Define a fluid model with:
- **Viscosity**
- **Thermal expansion coefficient** of the fluid
- **Compressibility** or bulk modulus
- **Volumetric heat capacity** - set to a **negligible value** to ignore thermal convection effects; this ensures that only thermal diffusion (conduction) is considered in the heat transfer

## 4. Initial Conditions

### Initial Stress State:
- Set **initial effective stresses** consistent with the initial temperature change using the relationship: σ₀ = 3Kα·δT₀, where σ₀ is the initial effective principal stress, K is the drained bulk modulus, α is the drained linear thermal expansion coefficient, and δT₀ is the initial temperature change
- If the initial temperature change is **zero**, then the initial effective stresses should be set to **zero**

### Initial Temperature:
- Define the **initial temperature field** throughout the domain (this also serves as the far-field reference temperature)

### Initial Pore Pressure:
- Set the **initial pore pressure** distribution throughout the rock formation

## 5. Boundary Conditions

### Mechanical Boundary Conditions for Axisymmetric Plane Strain:
- Apply **symmetry conditions** on the theta = 0 degree face (constrain displacement normal to this face)
- Apply **symmetry conditions** on the theta = 90 degree face (constrain displacement normal to this face)
- These conditions enforce the axisymmetric behavior

### Far-Field Boundary (Outer Radius):
- Apply **fixed displacement** boundary condition (all displacement components constrained to zero)
- This represents the assumption that local changes near the wellbore have negligible effect at the far-field boundary

### Wellbore Inner Surface:
- Apply **traction-free** boundary condition (zero traction/stress on the inner surface)
- This represents an open, unsupported wellbore

### Temperature Boundary Conditions:
- Apply a **temperature Dirichlet condition** on the inner wellbore surface specifying the changed temperature
- The far-field boundary temperature should remain at the **initial temperature value**

### Pore Pressure Boundary Conditions:
- Define **pore pressure conditions** on the inner wellbore surface
- Define **pore pressure conditions** at the far-field boundary
- Specify both initial values and boundary conditions for pressure

## 6. Numerical Method Specifications

### Solver Configuration:
- Use the **SinglePhasePoromechanics** solver
- Enable the **thermal** option/capability
- Configure for **fully coupled** thermoporomechanical analysis

### Time Stepping:
- Define appropriate time stepping parameters for the transient thermal diffusion problem
- Set up periodic events to trigger output collection throughout the simulation duration

## 7. Output Requirements

### Output Format:
- Use **HDF5 format** for output data to facilitate post-processing with Python

### Field Data Collection:
Configure the following field data collectors:

1. **Temperature Field:**
   - Create a PackCollection object to collect temperature data
   - Create a corresponding TimeHistory task to write the temperature collection
   - Collect for all time steps

2. **Effective Stress Field:**
   - Create a PackCollection object to collect solid stress data from the element region
   - Create a corresponding TimeHistory task for stress output
   - Collect stress components across the entire domain

3. **Displacement Field:**
   - Create a PackCollection object targeting the **nodeManager** to collect displacement data
   - Create a corresponding TimeHistory task for displacement output

### Periodic Events:
- Define **PeriodicEvent** objects to trigger data collection at regular intervals throughout the simulation
- Ensure events are linked to the appropriate collection and output tasks
- Set appropriate time intervals that capture the transient behavior adequately

## File Organization Note

The configuration may be split into two XML files:
1. A **base file** containing material properties, boundary conditions, constitutive definitions, and output specifications
2. A **benchmark file** containing mesh definition, time events, and simulation-specific parameters that includes/references the base file
