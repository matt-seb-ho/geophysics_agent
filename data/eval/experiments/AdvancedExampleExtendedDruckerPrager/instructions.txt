# Natural Language Specification for Extended Drucker-Prager Triaxial Driver Validation

## 1. Simulation Type and Physical Problem

This simulation models an elasto-plastic triaxial compression test using the Triaxial Driver solver to validate the Extended Drucker-Prager constitutive model implementation in GEOS. The test involves:

- A single material element subjected to triaxial stress conditions
- Constant lateral (horizontal) confining stress throughout the simulation
- Cyclic axial strain loading and unloading periods
- Strain magnitudes sufficient to induce plastic yielding during both loading and unloading phases
- The purpose is verification of numerical convergence and accuracy against semi-analytical solutions

## 2. Solver Requirements

Configure a **TriaxialDriver** solver (not a traditional physics solver with mesh) that:

- Operates on a single material point/element to test constitutive behavior
- References the Extended Drucker-Prager constitutive model
- Applies prescribed strain-controlled loading in the axial direction
- Maintains stress-controlled conditions in the lateral direction

## 3. Mesh Requirements

For the Triaxial Driver, no traditional mesh is required. This is a material point simulation that tests the constitutive model at a single integration point. The driver internally handles the stress-strain computations without spatial discretization.

## 4. Material Properties and Constitutive Model

Create an **ExtendedDruckerPrager** constitutive model with the following parameters (all in SI units):

**Elastic Properties:**
- Specify density (kg/m³)
- Define bulk modulus OR Young's modulus (Pa)
- Define shear modulus (Pa)

**Plastic Properties (Extended Drucker-Prager specific):**
- Initial cohesion parameter defining the yield surface (Pa)
- Frictional parameter (b) - dimensionless
- Dilation ratio (θ) - dimensionless
- Hardening parameters defining the evolution of the yield surface

The model uses the Extended Drucker-Prager yield criterion where the yield function depends on the mean stress and deviatoric stress invariant, with parameters controlling friction, dilation, and hardening behavior.

## 5. Initial and Boundary Conditions

Define these conditions within the **Task** block:

**Initial Stress State:**
- Specify the initial stress tensor components
- Define initial axial (vertical) stress
- Define initial lateral (horizontal) stress

**Lateral Confining Stress:**
- Apply constant horizontal stress maintained throughout the simulation
- This acts as a stress-controlled boundary in the lateral directions

**Axial Strain Loading Protocol:**
- Define axial strain as a function of time using table files
- Include loading periods (increasing compressive strain)
- Include unloading periods (decreasing strain)
- Strain magnitudes must be large enough to trigger plastic yield in both directions
- Reference table files located in the `tables/` subdirectory for the strain history

## 6. Numerical Method Specifications

The Triaxial Driver uses:

- Implicit stress integration for the constitutive model
- Return mapping algorithm for the Extended Drucker-Prager plasticity
- The driver iterates to satisfy the mixed boundary conditions (strain-controlled axially, stress-controlled laterally)

No additional numerical parameters (time stepping, convergence tolerances) are explicitly mentioned, suggesting default values are used.

## 7. Output Requirements

Configure output to:

- Generate a text file named **ExtendedDruckerPragerResults.txt**
- Output should contain the stress-strain history including:
  - Axial strain variations (Δε_V)
  - Axial stress variations (Δσ_V)
  - Lateral strain variations (Δε_H)
  - Potentially plastic strain and internal variable history

## 8. File Structure Requirements

The configuration should be split across two XML files:

**Base file (triaxialDriver_base.xml):**
- Contains the Extended Drucker-Prager material definition with all constitutive parameters

**Problem-specific file (triaxialDriver_ExtendedDruckerPrager.xml):**
- Contains the Task definition with loading conditions
- References or includes the base file
- Specifies the strain/stress loading tables

**Supporting table files:**
- Located in a `tables/` subdirectory
- Define the time history of applied axial strains
- Define the constant lateral stress values

## 9. Units Convention

All parameters must be specified in the **International System of Units (SI)**:
- Stresses and moduli in Pascals (Pa)
- Density in kg/m³
- Strains are dimensionless
- Time in seconds (if applicable)

Note: The simulation uses a negative sign convention for compressional stress, which affects the semi-analytical solution formulation but should be handled consistently in the input specification.
