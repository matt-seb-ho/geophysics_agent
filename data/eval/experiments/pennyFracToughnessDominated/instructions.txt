# Specification for Toughness-Storage-Dominated Penny-Shaped Hydraulic Fracture Simulation

## 1. Simulation Type and Physical Problem

This simulation models the growth of a radial (penny-shaped) hydraulic fracture in a toughness-storage-dominated propagation regime. The problem represents a planar fracture with an elliptical cross-section perpendicular to the fracture plane and a circular fracture tip, emerging from a point source in an infinite, isotropic, homogeneous elastic domain. Due to symmetry, only a quarter of the domain is modeled to reduce computational cost.

The physics involves coupling between:
- Fluid flow within the fracture (lubrication equation from mass conservation and Poiseuille's law)
- Rock deformation
- Fracture deformation and propagation

Fracture propagates when the stress intensity factor exceeds the local rock toughness. The simulation assumes an impermeable fracture surface (no fluid leak-off).

## 2. Solver Configuration

### Primary Coupled Solver
Create a Hydrofracture solver that couples three sub-solvers:

### Solid Mechanics Solver
- Type: SolidMechanicsLagrangianFEM
- Target regions must include both the continuum rock region and the fracture region
- Must specify a contact relation name for the contact constitutive behavior

### Fluid Flow Solver
- Type: SinglePhaseFVM (single-phase finite volume method)
- Applied to the fracture region for flow within the fracture

### Surface Generator Solver
- Type: SurfaceGenerator
- Rock toughness: 3.0e6 Pa·m^(1/2) (equivalent to 3.0 MPa·m^(1/2))
- Use node-based Stress Intensity Factor calculation (nodeBasedSIF = 1)
- Defines the fracture region and propagation criterion

## 3. Mesh Requirements

### Domain Geometry
- Computational domain dimensions: 400 meters × 400 meters × 800 meters (x, y, z)
- The z-axis is perpendicular to the fracture plane
- Domain size in z-direction must be at least 10 times the expected final fracture radius to minimize boundary effects

### Mesh Discretization
- Use InternalMesh generator
- Element count: 80 × 80 × 60 elements in x, y, and z directions respectively
- Element type: C3D8 (eight-node hexahedral brick elements)
- Cell block name: cb1
- Apply local mesh refinement in the vicinity of the fracture plane

### Fracture Plane Definition
- Define a nodeset occupying a small region within the computational domain where the fracture will initiate and propagate
- This nodeset represents the fracture plane location for fluid injection

## 4. Material Properties and Constitutive Models

### Rock Properties (ElasticIsotropic model)
- Material name: rock
- Bulk Modulus (K): 20.0 GPa (20.0e9 Pa)
- Shear Modulus (G): 12.0 GPa (12.0e9 Pa)
- Rock Toughness (K_IC): 3.0 MPa·m^(1/2) (specified in SurfaceGenerator as 3.0e6)

### Fluid Properties (CompressibleSinglePhaseFluid model)
- Material name: water
- Viscosity (μ): 1.0×10^(-6) Pa·s (equivalent to 0.001 centipoise - ultra-low viscosity)
- Density must be specified (value used in injection rate calculation)

All constitutive parameters must be specified in SI units.

## 5. Initial and Boundary Conditions

### Initial Conditions
The following fields must be initialized:
- Water density field (waterDensity)
- Separable face indicator (separableFace) for identifying potential fracture surfaces
- Rupture state (ruptureState) of the propagating fracture elements

### Boundary Conditions

#### Fluid Injection
- Type: SourceFlux
- Location: Surfaces of the initial fracture
- Scale value: -6.625 (this represents Q₀ × ρ_f / 4, accounting for quarter symmetry)
- Full injection rate Q₀: 0.0265 m³/s
- Injection duration: 400 seconds

#### Mechanical Boundary Conditions
- Apply roller constraints on all outer boundaries of the domain
- This prevents normal displacement while allowing tangential movement

## 6. Numerical Method Specifications

- Quarter-symmetry model exploiting problem symmetry
- Finite volume method for single-phase fluid flow in fracture
- Lagrangian finite element method for solid mechanics
- Node-based Stress Intensity Factor (SIF) calculation for fracture propagation criterion
- Plane strain deformation assumption for verification purposes
- Impermeable fracture surfaces (no leak-off modeling)
- Incompressible fluid behavior with ultra-low viscosity to ensure toughness-storage-dominated regime

## 7. Output Requirements

### Time History Collection Tasks
Create PackCollection tasks in the Tasks section to collect time history data from the fracture:

1. **pressureCollection** - collects fluid pressure history
2. **apertureCollection** - collects fracture aperture (width) history
3. **hydraulicApertureCollection** - collects hydraulic aperture history
4. **areaCollection** - collects fracture element area history

All tasks should have:
- Object path: ElementRegions/Fracture/FractureSubRegion

### Event Configuration
- Create a PeriodicEvent to trigger the time history collection tasks at regular intervals

### Output File
- Format: HDF5
- Filename: pennyShapedToughnessDominated_output.hdf5
- Contents: simulation time, fluid pressure, element aperture, hydraulic aperture, and element area for the propagating hydraulic fracture
