# Natural Language Specification for Deviated Poro-Elastic Wellbore Injection Simulation

## Overview and Simulation Type

Create an XML configuration file for a coupled poroelastic simulation of a deviated wellbore subjected to fluid injection. This simulation models the pressure diffusion and stress redistribution in the near-wellbore region during fluid injection into an open-hole completion. The problem assumes poroelastic deformation without in-situ stresses or gravity effects. The configuration should be split into two files: a base file containing material properties and boundary conditions, and a benchmark file containing solver definitions and mesh specifications.

## Solver Configuration

### Primary Coupled Solver
Define a coupled poroelastic solver that coordinates between solid mechanics and fluid flow. This solver must:
- Be of type "Poroelastic" (or equivalent coupled hydromechanical solver)
- Reference both a solid mechanics solver and a single-phase flow solver by name
- Define a coupling strategy between the mechanical and flow components

### Solid Mechanics Solver
Configure a solid mechanics solver with the following specifications:
- Solver type: SolidMechanicsLagrangianFEM (Lagrangian finite element method)
- Must be registered with a name that the poroelastic solver can reference
- Target the wellbore region mesh

### Flow Solver
Configure a single-phase flow solver with the following specifications:
- Solver type: SinglePhaseFVM (finite volume method for single-phase flow)
- Must be registered with a name that the poroelastic solver can reference
- Target the same wellbore region as the mechanics solver

## Mesh Requirements

### Mesh Generator Type
Use the internal wellbore mesh generator (InternalWellbore) to create the computational domain.

### Geometric Parameters
- **Radius specification**: Define a vector of radii that specifies the wellbore radius and the extent of the surrounding rock formation (from wellbore wall to far-field boundary)
- **Angular extent (theta)**: Specify from 0 to 180 degrees to model half the domain, taking advantage of symmetry. Note: For non-symmetric or complex scenarios, the full 360-degree domain could be specified
- **Wellbore trajectory**: Define a trajectory that creates a deviated wellbore inclined at 45 degrees in the x-z plane

### Mesh Control Parameters
- **autoSpaceRadialElems**: Set to 1 (enabled) to allow automatic optimal spacing of radial elements, with finer mesh near the wellbore transitioning to coarser mesh in the far-field
- **useCartesianOuterBoundary**: Set to 0 (disabled) for this single-region radial domain. This parameter would transform the outer boundary to a square shape if enabled

### Element Types
The mesh should generate appropriate 3D elements suitable for both the finite element solid mechanics solver and the finite volume flow solver.

## Material Properties and Constitutive Models

### Rock Mechanical Properties
Define an isotropic elastic constitutive model (ElasticIsotropic) with:
- Bulk modulus (specify the value used for the rock formation)
- Shear modulus (specify the value used for the rock formation)
- These values should be consistent with computing appropriate Poisson ratio for the analytical solution comparison

### Fluid Properties
Define a compressible single-phase fluid model (CompressibleSinglePhaseFluid) including:
- Dynamic viscosity
- Fluid compressibility

### Porosity Model
Define a Biot porosity model (BiotPorosity) containing:
- Grain bulk modulus (required for computing the Biot coefficient)
- Default/reference porosity value

### Permeability Model
Define a constant permeability model (ConstantPermeability) with:
- Uniform isotropic permeability value for the formation

## Initial Conditions

Specify initial conditions for the computational domain:
- **Initial fluid pressure**: Define the initial pore pressure throughout the domain
- **Initial porosity**: Provide the corresponding initial porosity consistent with the Biot porosity model

## Boundary Conditions

### Far-Field Boundaries
- **Mechanical**: Apply roller constraints (zero normal displacement) on the far-field boundaries
- **Flow**: Set impermeable conditions (zero flux) on the far-field boundaries

### Wellbore Wall Boundary
- **Location**: Apply to the nodeset named "rneg" which is automatically generated by the internal wellbore mesh generator for the wellbore face
- **Pressure loading**: Define a face pressure field specification
- **Injection pressure**: The scale value should be negative to denote fluid injection (pressure applied into the formation)
- **Pressure value**: Set to p0 (the characteristic injection pressure used in the analytical solution, value needed for comparison)

### Symmetry Boundaries
Apply appropriate symmetry conditions on the planes of symmetry (at theta = 0 and theta = 180 degrees)

## Numerical Method Specifications

The simulation requires:
- Coupled hydromechanical formulation based on poroelasticity theory
- Lagrangian finite element discretization for solid mechanics
- Finite volume discretization for single-phase flow
- Time-stepping scheme capable of capturing the transient diffusion process
- Simulation should run for at least 78 seconds to capture the pressure diffusion results shown in validation

## Output Requirements

Configure outputs to capture:
- Fluid pressure distribution in the near-wellbore region (for visualization and validation against analytical solutions)
- Radial stress distribution along the radial direction from wellbore
- Hoop stress distribution for comparison with analytical expressions
- Results should be extractable for comparison with the Detournay and Cheng (1988) analytical solutions involving:
  - Pore pressure as a function of dimensionless radius and time
  - Radial stress incorporating Biot coefficient and Poisson ratio effects
  - Hoop stress computed from pressure and radial stress

## File Organization

The configuration should be organized into two XML files:
1. **Base file** (DeviatedPoroElasticWellbore_Injection_base.xml): Contains material/constitutive definitions and boundary condition specifications
2. **Benchmark file** (DeviatedPoroElasticWellbore_Injection_benchmark.xml): Contains solver definitions and mesh specifications, with includes/references to the base file
