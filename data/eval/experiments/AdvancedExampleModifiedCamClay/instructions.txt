# Natural Language Specification for Modified CamClay Triaxial Driver Simulation

## Simulation Overview

This configuration defines a **Triaxial Driver** simulation that models an **elasto-plastic oedometric compression test** using the **Modified CamClay** constitutive model. The Triaxial Driver is a material testing solver that applies specified strain or stress conditions to evaluate constitutive model behavior without requiring a full finite element mesh.

## Solver Configuration

### Solver Type and Settings
- **Solver Type**: TriaxialDriver (a specialized solver for testing constitutive models)
- **Purpose**: Validate the Modified CamClay viscoplastic material model against semi-analytical solutions
- The solver should be configured to handle elasto-plastic material response with loading and unloading cycles

## Task Block Specifications

The Task block must define the following testing conditions:

### Loading Conditions
- **Axial Strain**: Define loading and unloading periods for axial strain (vertical direction)
- **Lateral Strain**: Enforce zero lateral strain to achieve oedometric conditions (constrained laterally, loaded axially)
- **Initial Stress State**: Specify the initial stress conditions for the test

### Strain Path
- The simulation should include multiple loading/unloading cycles to test both elastic and plastic responses
- Table files from the `inputFiles/triaxialDriver/tables/` directory should be referenced to define the strain time history

## Constitutive Model Requirements

### Material Type
- **Constitutive Model**: ModifiedCamClay (elasto-plastic model with pressure-dependent yield surface)

### Required Material Parameters
The Modified CamClay model requires the following parameters, all specified in **SI units**:

1. **Elastic Properties**:
   - Bulk modulus (K) - controls volumetric elastic response
   - Shear modulus (μ) - controls deviatoric elastic response

2. **Plastic Properties**:
   - Parameters defining the yield surface (F)
   - Parameters defining the plastic potential (G)
   - Hardening parameters related to volumetric plastic strain

3. **Other Properties**:
   - Density
   - Viscosity (for rate-dependent behavior)

### Model Equations Context
The constitutive model implements:
- A yield surface F and plastic potential G
- A hardening rate h defined by: h = -(∂F/∂ε_vol^vp)(∂G/∂p)
- The relationship between volumetric strain changes and stress changes (Δp for mean stress, Δq for shear stress)

## Mesh Requirements

This is a **Triaxial Driver** simulation, which is a single-element or point-wise material test. Therefore:
- No complex mesh geometry is required
- The driver tests material behavior at a single integration point
- No spatial discretization specifications are needed

## Boundary and Initial Conditions

### Initial Conditions
- Initial stress state must be specified in the Task block
- The material should start from a specified initial stress configuration

### Boundary Conditions (Constraint Conditions)
- **Oedometric Constraint**: Zero lateral strain (ε_lateral = 0)
- **Axial Loading**: Controlled axial strain with loading/unloading history

## Input File Structure

The configuration uses a **two-file structure**:

1. **Base File** (`triaxialDriver_base.xml`): Contains the constitutive model definitions including the Modified CamClay material parameters

2. **Main File** (`triaxialDriver_ModifiedCamClay.xml`): Contains the Task definitions specifying loading conditions, strain paths, and initial stress states. This file should include/reference the base file.

### External Table Files
- Reference table files from the `tables/` subdirectory for defining the strain loading history over time

## Output Requirements

### Output File
- **Filename**: `ModifiedCamClayResults.txt`
- **Format**: Text file containing simulation results

### Output Data
The output should include data sufficient to:
- Compare mean stress (p) evolution with semi-analytical solutions
- Compare shear stress (q) evolution with semi-analytical solutions
- Track the stress path during loading/unloading cycles
- Verify elastic and plastic strain components

## Numerical Considerations

- The simulation tests both elastic and plastic regimes of the Modified CamClay model
- Loading/unloading cycles should demonstrate proper elastic unloading behavior
- The model should correctly transition between elastic and plastic states based on the yield criterion

## Units

All parameters must be specified in the **International System of Units (SI)**:
- Stress and moduli: Pascals (Pa)
- Density: kg/m³
- Strain: dimensionless
- Viscosity: Pa·s
