# Natural Language Specification for Vertical PoroElasto-Plastic Wellbore Simulation

## Overview and Simulation Type

This specification describes a coupled poromechanical simulation of a vertical wellbore problem in porous media. The simulation models rock deformation near a wellbore considering elastoplastic deformation, fluid diffusion, and poromechanical coupling effects. Two variants of this simulation exist: a poroelastic version for verification purposes and a poroplastic version that captures plastic deformation behavior. The problem involves a vertical wellbore subjected to anisotropic stress conditions with mechanical and fluid loading applied at the wellbore wall.

## Solver Configuration

The simulation requires three solver definitions that work together:

### Primary Mechanics Solver
Create a solid mechanics solver of type "SolidMechanicsLagrangianFEM" with the name "mechanicsSolver". This solver handles the mechanical deformation using a Lagrangian finite element method.

### Flow Solver
Create a single-phase flow solver of type "SinglePhaseFVM" with the name "SinglePhaseFlowSolver". This solver handles fluid flow using the finite volume method.

### Coupling Solver
Create a coupling solver of type "SinglePhasePoromechanics" with the name "PoromechanicsSolver". This solver must reference the fluid solver "SinglePhaseFlowSolver" and the solid solver "mechanicsSolver". The porous material name should be set to "porousRock". The discretization method should reference "FE1" and the target region should be "Omega".

## Mesh Configuration

Use the internal wellbore mesh generator "InternalWellbore" to create the computational domain with the following specifications:

- **Domain dimensions**: 10 meters by 5 meters by 2 meters
- **Wellbore radius**: 0.1 meters (initial radius)
- **Wellbore trajectory**: Define trajectory coordinates that represent a perfect vertical well
- **Automatic radial element spacing**: Enable using autoSpaceRadialElems set to "{ 1 }", which automatically determines the number and spacing of elements in the radial direction
- **Outer boundary type**: Set useCartesianOuterBoundary to "0" to enforce a Cartesian-aligned outer boundary on the outer block
- **Element counts**: The mesh should contain 100 elements in the radial direction, 80 elements in the tangential direction, and 2 elements in the z-direction
- **Element type**: Eight-node hexahedral elements (C3D8)
- **Cell block name**: Name the cell block "cb1"

The mesh generator will create refinement that conforms to the wellbore geometry.

## Numerical Methods

### Finite Element Discretization
Define a finite element discretization method named "FE1" using linear basis functions and Gaussian quadrature rules. This method is used by both the coupling solver and the solid mechanics solver.

### Finite Volume Discretization
Define a two-point flux approximation scheme named "singlePhaseTPFA" for the flow discretization.

## Constitutive Models and Material Properties

### For Poroelastic Case

**Solid Material (rock)**:
Use the "PorousElasticIsotropic" model with the following properties:
- Bulk Modulus: 11.11 GPa
- Shear Modulus: 8.33 GPa

**Fluid Material (water)**:
Use the "CompressibleSinglePhaseFluid" model with:
- Density: 1000.0 kg/m³
- Viscosity: 0.001 Pa·s
- Compressibility: 2.09 × 10⁻¹⁰ Pa⁻¹

### For Poroplastic Case

**Solid Material (rock)**:
Use the "PorousExtendedDruckerPrager" model with:
- Bulk Modulus: 11.11 GPa
- Shear Modulus: 8.33 GPa
- Default Cohesion: 1.0 MPa
- Default Initial Friction Angle: 15.27 degrees
- Default Residual Friction Angle: 23.05 degrees
- Default Hardening Rate: 0.01 (since residual friction angle is larger than initial, strain hardening is automatically selected)
- Default Dilation Ratio: 1.0 (corresponds to an associated flow rule)

**Fluid Material (water)**:
Use the "CompressibleSinglePhaseFluid" model with identical properties as the poroelastic case.

### Porosity and Permeability Models

**Porosity Model (rockPorosity)**:
Define a stress-dependent porosity model with:
- Reference porosity: 0.3

**Permeability Model (rockPerm)**:
Define a constant permeability model with:
- Permeability: 1.0 × 10⁻²⁰ m²

## Initial Conditions

All initial condition fields must have the initialCondition attribute set to "1".

### Initial Stress State
Apply anisotropic in-situ stresses:
- Minimum horizontal stress (σh): -9.0 MPa (compression is negative)
- Maximum horizontal stress (σH): -11.0 MPa
- Vertical stress (σv): -12.0 MPa

### Initial Pore Pressure
Initialize the pore pressure field throughout the domain as required for the coupled simulation.

## Boundary Conditions

### Wellbore Wall Conditions (applied to surface "rneg")

**Mechanical Loading (InnerMechanicalLoad)**:
- Apply a normal traction with tractionType set to "normal"
- Scale value: -10.0e6 (representing -10 MPa compressive traction)
- The traction is computed as the product of the scale value and the outward face normal
- Use a table function named "timeFunction" to define time-dependent loading

**Fluid Loading (InnerFluidLoad)**:
- Apply fluid pressure of 10.0 MPa at the wellbore wall
- Use the same time function for time-dependent behavior

### Outer Boundary Conditions

Apply roller constraints to all outer boundary surfaces. Use the shorthand notations:
- "xneg" for the left-most boundary in x-direction
- "xpos" for the right-most boundary in x-direction  
- "yneg" for the left-most boundary in y-direction
- "ypos" for the right-most boundary in y-direction
- "zpos" for the top boundary in z-direction
- "zneg" for the bottom boundary in z-direction

The boundary conditions should constrain normal displacement while allowing tangential movement (roller conditions).

### Time Function Definition

Create a table function named "timeFunction" that defines coordinates (time values) and corresponding values (magnitude multipliers) to specify the time history of the loading. This function controls how the wellbore wall loads are applied over the simulation duration.

## Field Specifications Notes

When specifying field conditions:
- Use "nodeManager" in the objectPath for boundary conditions applied to element nodes
- Use "faceManager" in the objectPath for boundary conditions applied to element faces
- Use component indices 0, 1, and 2 to refer to x, y, and z directions respectively
- The fieldName attribute must match the registered field names in GEOS
- The setName attribute should reference previously defined geometric sets or shorthand boundaries

## Output Configuration

### Simulation Duration
Configure the Events section to run the simulation for 497,640 seconds. This corresponds to a non-dimensional end time of t* = 4.62 when using the analytical solution scaling.

### Output Format
Request silo-format output files for visualization in tools such as VisIt.

### Output Variables
The simulation should output fields including:
- Pore pressure distribution
- Radial displacement
- Effective radial stress
- Effective tangential stress
- For the poroplastic case: stress components (particularly σyy) to observe stress relaxation due to plasticity

## Region Definition

Define a single computational region named "Omega" that encompasses the entire rock domain. Both the coupling solver and individual physics solvers should target this region. Associate the porous material "porousRock" with this region, linking together all the constitutive models (solid, fluid, porosity, permeability).
