# Natural Language Specification for Non-Linear Thermal Diffusion Around a Wellbore XML Configuration

## Overview and Simulation Type

Create an XML configuration file for a **non-linear thermal diffusion simulation** around a wellbore geometry. This simulation models heat transfer in porous rock surrounding a wellbore where the volumetric heat capacity of the solid rock varies linearly with temperature. The simulation uses a **thermal single-phase flow solver** to capture the coupled thermal-hydraulic behavior.

This is a 2D axisymmetric or radial problem centered on a wellbore.

## Solver Configuration

Configure a **thermal compressible single-phase flow solver** with the following requirements:

- The solver must be capable of handling non-linear thermal diffusion problems
- Enable thermal effects in the single-phase flow formulation
- The solver should account for temperature-dependent material properties
- Configure the solver to use appropriate non-linear iteration schemes since the volumetric heat capacity introduces non-linearity through its temperature dependence

## Mesh Requirements

The mesh should represent a 2D domain around a wellbore:

- Use a radial or annular mesh geometry extending outward from the wellbore wall
- The inner boundary represents the wellbore surface
- The outer boundary should be far enough to approximate infinite medium conditions
- Element type should be appropriate for 2D thermal analysis (likely quadrilateral elements)
- Mesh refinement should be concentrated near the wellbore where temperature gradients are steepest

## Constitutive Models

### Solid Internal Energy Model (Critical Component)

This is the key constitutive specification for this example. Define a **SolidInternalEnergy** model with temperature-dependent volumetric heat capacity:

- Specify a **reference volumetric heat capacity** value for the rock medium
- Define the **derivative of volumetric heat capacity with respect to temperature** (dVolumetricHeatCapacity_dTemperature) to capture the linear temperature dependence
- The relationship should be: volumetric heat capacity = reference value + (derivative × temperature change)

### Additional Constitutive Models

- Define thermal conductivity properties for the rock medium
- Specify fluid properties if the single-phase flow component is active
- Include rock porosity and permeability properties as required by the thermal single-phase flow solver
- Define rock compressibility and thermal expansion coefficients

## Material Properties

For the rock/solid medium surrounding the wellbore:

- Reference volumetric heat capacity (specify the base value at reference temperature)
- Temperature derivative of volumetric heat capacity (captures the linear dependence)
- Thermal conductivity of the solid matrix
- Density of the solid rock

For any fluid phase present:

- Fluid thermal properties
- Fluid density and compressibility

## Initial Conditions

- Specify an initial temperature distribution throughout the domain (typically uniform far-field temperature)
- Define initial pressure conditions if required by the thermal single-phase solver

## Boundary Conditions

### Wellbore Boundary (Inner Boundary)

- Apply a thermal boundary condition at the wellbore wall (either prescribed temperature or heat flux)
- This represents the thermal perturbation source for the diffusion problem

### Far-Field Boundary (Outer Boundary)

- Apply appropriate far-field conditions (typically constant temperature representing undisturbed formation temperature)
- May use large domain extent to approximate infinite boundary conditions

## Numerical Method Specifications

- Configure time-stepping appropriate for transient thermal diffusion
- Set up non-linear solver tolerances to handle the temperature-dependent heat capacity
- Newton-Raphson or similar iterative scheme may be required due to material non-linearity
- Specify convergence criteria for the non-linear iterations

## Output Requirements

- Record temperature field at specified time intervals
- Output should enable comparison with analytical or finite difference reference solutions
- Include radial temperature profiles from wellbore outward at various time steps
- Results should be suitable for generating temperature vs. radial distance plots at different times for validation against classical finite difference method solutions

## File Structure

The configuration should be organized to potentially use two XML files:

1. A **base configuration file** containing the fundamental 2D thermal compressible flow setup, mesh definition, and general solver parameters
2. A **benchmark-specific file** that includes or overrides settings specific to the temperature-dependent volumetric heat capacity case, particularly the SolidInternalEnergy constitutive definition with the non-linear (temperature-dependent) parameters
