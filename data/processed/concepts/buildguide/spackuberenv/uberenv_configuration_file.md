## Uberenv configuration file
Uberenv needs a `.uberenv_config.json ](https://github.com/GEOS-DEV/thirdPartyLibs/blob/master/.uberenv_config.json) configuration file to function as a submodule.
Details on the various configuration options can be found in [Uberenv project configuration documentation ](https://uberenv.readthedocs.io/en/latest/#project-configuration). The most notable option for maintenance is [spack_commit`, which is the Spack commit that Uberenv checkouts to build the dependencies.
